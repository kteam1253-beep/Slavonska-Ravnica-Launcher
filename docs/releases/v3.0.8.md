- Ispravljeno nepotrebno označavanje svih postojećih modova za UPDATE nakon verzije 3.0.7.
- Launcher uspoređuje popis datoteka, veličine i kontrolne zbrojeve unutar lokalnog i serverovog ZIP-a, uz dohvat samo dijela serverove arhive.
- Podudarni modovi prelaze u OK bez ponovnog preuzimanja. Različit sadržaj označava se za UPDATE, čak i uz isti broj verzije.
- Ako server ne podržava djelomičnu provjeru ili provjera ne uspije, mod se prikazuje pod Greška i ne uključuje se automatski u ažuriranje svih modova.

Nakon instalacije klikni Sinkroniziraj i pričekaj dovršetak prve provjere. Potvrđeni modovi pamte se za iduće provjere. Preuzmi samo modove koji nakon provjere ostanu pod UPDATE ili FALI.
